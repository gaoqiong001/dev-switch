# Dev Switch v0.2.0

> **核心升级：迁移到 Tauri v2**，并让「静默自动更新」真正端到端跑通 —— 参考 cc-switch 重构了签名与发布流水线：CI 直接签名 `.msi`（产出 `.msi.sig`），`latest.json` 指向签名后的 `.msi`，应用内「检查更新 / 自动安装」从此可验证并安装真实 Release。

**[English →](v0.2.0-en.md)**

---

## 核心变化

- **迁移到 Tauri v2**：后端从 Tauri v1.8.3 升级到 v2.8.0（与 cc-switch 同款底座），配置改写为 v2 schema（`app` / `bundle.createUpdaterArtifacts` / `plugins.updater`），新增 `capabilities/` 权限声明。
- **自动更新真正可用**：v2 直接签名 `.msi` 生成 `.msi.sig`；发布资产变为 `.msi` + `.msi.sig` + `-setup.exe` + 真实签名/地址的 `latest.json`（此前 v1 链路签名格式与 `latest.json` 不匹配，更新始终无法落地）。
- **前端依赖升级**：`@tauri-apps/api` / `@tauri-apps/cli` 升至 2.x，`invoke` 入口迁移到 `@tauri-apps/api/core`。
- **修复下载进度显示**：进度事件改为累计字节数（`downloaded`），进度条不再跳变。
- **CI 发布流水线重构**：签名密钥规范化 + 密码必填校验（缺失即快速失败），与 cc-switch 对齐。

---

## 升级方式

- **已安装 v0.1.0**：打开应用后，内置更新机制会检测到 v0.2.0 并自动下载安装（若已在 **设置 → 启动选项 → 自动下载并安装更新** 中启用）。
- **全新安装**：从 [Releases](https://github.com/gaoqiong001/dev-switch/releases) 下载 `.exe` 或 `.msi`。
