# Dev Switch v0.1.0

> **Dev Switch** 的首个公开版本 —— 一个基于 Tauri 的桌面应用，一键检测并展示你的本地开发环境：系统信息、19 种编程语言、50+ 种开发工具与网络详情，附带各系统的安装/卸载指引，结果缓存在 SQLite 中，后续启动即时返回。当前支持 Windows（macOS/Linux 安装包计划中）。

## 核心亮点

- **一键全面盘点**：一次扫描检测 19 种语言和 50+ 种工具；已安装的排在前面。
- **干净整洁的版本号**：原始 `--version` 输出会被清洗为版本号本体（例如 `curl 8.21.0 (Windows) …` → `8.21.0`）。
- **按系统给出的指引**：每个条目都附带 Windows / macOS / Linux 的安装、卸载命令。
- **系统与网络信息**：操作系统、主机名、CPU、内存，以及本地 IP 和网络接口。
- **静默自动更新**：内置更新机制，发现新版本自动下载安装（可在设置中关闭）；关闭后回退到打开下载页手动安装。
- **搜索、主题、导出**：按名称筛选；浅色/深色/跟随系统主题；紧凑模式；导出为 JSON/CSV。

## 概览

Dev Switch 是一款本地开发环境检测应用。它会扫描机器上已安装的运行时与工具，展示干净的版本号与安装路径，并按平台给出对应的安装/卸载指引。检测结果缓存在内置的 SQLite 数据库中，点击「刷新」前，后续启动都是即时读取。

## 新增功能

### 一键环境检测

一次扫描即可检测机器上已安装的 19 种编程语言和 50+ 种开发工具。系统信息（操作系统版本、主机名、CPU 核心数、内存大小）和网络详情（本地 IP、网络接口）一并包含。已安装的条目始终排在前面，便于快速识别。

### 干净整洁的版本号

原始 `--version` 输出被清洗为仅保留版本号。多行输出（VS Code）、banner 文本（curl）和版本前缀（v22.12.0）均能正确处理。版本清洗覆盖 19 种语言和 50+ 种工具，无需外部正则依赖。

### 按系统给出的安装与卸载指引

每个检测到的条目都包含平台特定的安装和卸载命令。Windows 用户获取 `winget` 或 `choco` 命令，macOS 用户获取 `brew` 命令，Linux 用户获取 `apt-get` 命令。每条指引针对具体工具量身定制。

### 静默自动更新

内置更新机制在启动时检查新版本（在 **设置 → 启动选项 → 启动时检查更新** 中启用），并通过 Tauri updater 静默下载安装。该功能可关闭 —— 关闭后检查更新会打开 GitHub Release 页面供手动下载。语义化版本比较确保正确的升级检测。

### 搜索、主题与导出

通过搜索栏按名称筛选语言和工具。在浅色、深色或跟随系统主题之间切换。紧凑模式减小间距以显示更多内容。检测结果可导出为 JSON 或 CSV，也可从之前的导出导入设置。

### SQLite 缓存

检测结果缓存在内置的 SQLite 数据库中。后续启动从缓存即时加载。点击「刷新」清除缓存并重新扫描。缓存有效期可在设置中配置。

## 升级提醒

- **无升级路径** — 这是首个版本，没有旧版本可升级；数据库在首次启动时全新创建，无需迁移。
- 从本版本起，后续更新通过内置的静默更新机制交付：新版本会自动下载并安装（可在 **设置 → 启动选项 → 自动下载并安装更新** 中关闭）。

## 下载与安装
