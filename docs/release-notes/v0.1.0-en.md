## Overview

Dev Switch is a local development-environment detection app. It scans the machine for installed runtimes and tools, reports clean version numbers and install paths, and opens the matching install/uninstall guide per platform. Detection results are cached in a bundled SQLite database, so subsequent launches are instant until you hit **Refresh**.

## Added

### One-Click Environment Detection

A single scan detects 19 programming languages and 50+ development tools installed on your machine. System information (OS version, hostname, CPU cores, total memory) and network details (local IP, network interfaces) are included. Installed items are always sorted to the front for quick identification.

### Clean Version Output

Raw `--version` output is cleaned to the version token only. Multi-line banners (VS Code), banner text (curl), and version prefixes (v22.12.0) are all handled. The version cleaning works across 19 languages and 50+ tools without external regex dependencies.

### Per-OS Install and Uninstall Guides

Every detected item includes platform-specific install and uninstall commands. Windows users get `winget` or `choco` commands, macOS users get `brew` commands, and Linux users get `apt-get` commands. Each guide is tailored to the specific tool.

### Silent Auto-Update

A built-in updater checks for new versions on startup (when enabled in **Settings → Startup → Check for updates on startup**) and downloads and installs them silently via the Tauri updater. The feature is toggleable — when disabled, checking for updates opens the GitHub Release page for manual download. Semantic version comparison ensures correct upgrade detection.

### Search, Themes, and Export

Filter languages and tools by name with the search bar. Switch between light, dark, or system-following themes. Compact mode reduces spacing for denser layouts. Export detection results as JSON or CSV, and import settings from a previous export.

### SQLite Cache

Detection results are cached in a bundled SQLite database. Subsequent launches load from cache instantly. Hit **Refresh** to clear the cache and re-scan. The cache expiry is configurable in Settings.

## Upgrade Notes

- **No upgrade path** — this is the first release; there is no previous version to upgrade from, and no database migration (schema is created fresh on first launch).
- Updates from this version onward are delivered via the built-in silent updater; new versions are downloaded and installed automatically (toggleable in **Settings → Startup → Auto-download and install updates**).
